# m4rt0s Home Assistant apps

My Home Assistant apps (add-ons) in one repository.

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fm4rt0s%2Fha-addons)

Settings → Apps → App store → ⋮ → Repositories → add
`https://github.com/m4rt0s/ha-addons`.

| App | What it does | Upstream |
|---|---|---|
| [PyPowerwall Server](pypowerwall-server/) | Local real-time data from a Tesla Powerwall, web console, MQTT with Home Assistant discovery | [jasonacox/pypowerwall-server](https://github.com/jasonacox/pypowerwall-server) |
| [Nutify](nutify/) | Web UPS monitoring on Network UPS Tools: live charts, alerts and reports | [DartSteven/Nutify](https://github.com/DartSteven/Nutify) |
